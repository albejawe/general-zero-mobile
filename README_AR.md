# General Zero Mobile — الإصدار 2.0

لعبة RTS مستقلة للجوال تعمل **عموديًا وأفقيًا**؛ ليست نسخة متكافئة مع Generals Zero Hour ولا تستخدم رسومها أو ملفاتها.

**موجود الآن:** 3 خرائط (1 ضد 1، 2 ضد 2، 4 ضد 4)، 3 جيوش، 3 مستويات صعوبة، اقتصاد ومصافٍ، مبانٍ عسكرية، 6 وحدات، ترقية أسلحة ودروع ومحركات، قصف تكتيكي وتعزيزات، تحديد مجموعات ونقاط تجمّع وخريطة مصغّرة. اللاعبون الآخرون خصوم/حلفاء يتحكم بهم الكمبيوتر، لا لعب شبكي.

**التحكم:** من «الإنشاءات» اختر مصفاة وضعها عند بلورات الموارد. ابنِ ثكنة ومصنعاً لإنتاج قواتك، ثم اختر الوحدات والمس أرضاً لتحريكها أو عدواً لمهاجمته. استخدم زر «الجيش» لتحديد الكل، وزر «تحديد ▱» للسحب حول مجموعة، وزر «هجوم» للتقدم مع الاشتباك. اسحب أرضاً فارغة لتحريك الكاميرا، وإصبعين للتكبير.

**تحديث PWA:** التطبيق يبحث عن تحديث عند فتحه أو عودته للواجهة. إذا انتهيت من اللعب يحدث تلقائياً، وإذا كانت المعركة جارية يعرض «تحديث الآن». لا حاجة لإلغاء تثبيت التطبيق أو تثبيته مجدداً. يلزم الاتصال والعودة للتطبيق حتى يتلقى التحديث؛ قد يختلف توقيت التنشيط حسب iOS/المتصفح. الإصدار يعتمد تحديث `sw.js` ونسخ `?v=` عند النشر.

**التشغيل:** افتح الموقع أو ملف `ZERO_FRONTIER_OFFLINE.html`، ويمكن إضافة الموقع إلى الشاشة الرئيسية. دعم التخزين بدون إنترنت بعد زيارة ناجحة.

**الفحص:** `python build_offline.py && python test_e2e.py && python test_gameplay_v2.py`. يجب اختبار أداء 4 ضد 4 وتحديث الـPWA على أجهزة حقيقية قبل وصف المشروع بأنه نهائي. لا توجد طائرات أو ضباب حرب أو لعب جماعي شبكي أو رسوم 3D تجارية بعد.
